# 支援の手がかりマップ

`index.html` をブラウザで開くだけで動く、独立した静的ミニアプリです。通信・ログイン・保存機能はありません。

5段階で観察内容を整理し、選択した「姿・前の状況・その後・見られにくい場面・強み・条件」を具体的に引用した見立てメモと、上位2〜4個の支援カテゴリを生成します。

## 構成

- `data.js`: 選択肢、支援カテゴリ、タグ対応、支援例、判定用の関連データ
- `app.js`: 画面遷移、選択状態、集計、結果表示、コピー処理
- `styles.css`: RELAY向けのカード型UI

RELAY本体へ組み込む際は、`SUPPORT_MAP_DATA` を既存のデータ管理方式へ移し、`app.js` の集計ロジックをコンポーネント側から呼び出せます。

見立てメモは外部AIでは生成していません。`app.js` の `buildMemo()`、`situationHint()`、`functionHint()` が、`data.js` の対応データと選択状態をもとにテンプレート文を条件分岐で組み合わせます。外部通信やAPIキーは使用しません。

## 確認方法

1. `index.html` をブラウザで開きます。
2. 各段階で当てはまるカードを選び、「支援の手がかりを見る」まで進みます。
3. 見立てメモ、上位カテゴリ、支援案、タグ、コピー内容を確認します。
4. 姿勢・移動・体の使い方を選んだ場合は、専門職との相談に関する注意文も表示されます。
